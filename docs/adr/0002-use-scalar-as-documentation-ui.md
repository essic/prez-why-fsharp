# 0002 — Use Scalar as the interactive API documentation UI

- Status: Accepted
- Date: 2026-11-10
- Workplan subject: `remove-nswag` — remove NSwag, convert the workshop API to Minimal API

## Context

With the OpenAPI document generated by the framework (ADR 0001), the workshop still needs a
browsable UI for participants. Swashbuckle/Swagger UI was the old default but is no longer the
.NET template default, and Microsoft's .NET 10 documentation recommends Scalar.

## Decision

Use `Scalar.AspNetCore` and `MapScalarApiReference()`, served at `/scalar` in development.
`launchSettings.json` opens `scalar` on launch.

## Consequences

- One small dependency replaces Swashbuckle and its transitive packages.
- The UI is only mapped in development, matching the OpenAPI document.
- The UI is a thin client of `/openapi/v1.json`; it adds no contract of its own.
